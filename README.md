## English

### 📝 About
This project is a dynamic Single Page Application (SPA) designed for managing and showcasing user-recommended songs. Built entirely with native frontend architecture, the application simulates navigation between different sections (Home, Expanded Info, and Contact) by asynchronously loading partial HTML views. This approach eliminates full-page browser reloads, delivering a smooth and modern user experience.

The core of the application features an interactive table tied to an external REST API, allowing users to view, add, edit, and delete songs in real-time (full CRUD lifecycle). Additionally, the project implements dynamic pagination, advanced filtering by release year, an automated mass-generator for rapid testing data, a contact form equipped with custom visual Captcha validation, and an adaptive User Interface toggle for Dark/Light mode.

### 🛠️ Technologies Used
* **HTML5:** Semantic document structure and partial view layouts.
* **CSS3:** Custom responsive styling optimized for mobile and desktop viewports.
* **JavaScript (Vanilla JS):** Native client-side logic, DOM manipulation, and asynchronous workflows.
* **AJAX / Fetch API:** Asynchronous handling of local partial HTML views and remote HTTP requests.
* **MockAPI:** Cloud service utilized to host the mock REST API backend and manage data persistence (songs database).

## Español

### 📝 Acerca de (About)
Este proyecto es una Single Page Application (SPA) dinámica orientada a la gestión y visualización de canciones recomendadas. Desarrollada con arquitectura frontend nativa, la aplicación simula la navegación entre diferentes secciones (Home, Información Expandida y Contacto) cargando contenido de forma asincrónica mediante vistas parciales, lo que evita la recarga completa del navegador y ofrece una experiencia de usuario fluida y moderna.

El núcleo de la aplicación incluye una tabla interactiva que consume una API REST externa, permitiendo a los usuarios visualizar, agregar, editar y eliminar canciones en tiempo real (operaciones CRUD completas). Además, cuenta con un sistema de paginación dinámica, filtros avanzados por año de lanzamiento, un generador automatizado de elementos de prueba para testing rápido, un formulario de contacto con validación de seguridad mediante código Captcha visual y un interruptor de interfaz adaptativa para Modo Oscuro (Dark/Light mode).

### 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructuración semántica de la interfaz y maquetación de las vistas parciales.
* **CSS3:** Diseño responsivo y estilizado adaptado a dispositivos móviles y de escritorio.
* **JavaScript (Vanilla JS):** Lógica del lado del cliente, manipulación del DOM y promesas.
* **AJAX / Fetch API:** Consumo asincrónico de recursos locales (HTML parciales) y peticiones remotas.
* **MockAPI:** Servicio en la nube utilizado para el despliegue del Backend simulado y persistencia de datos (Base de datos de canciones).
